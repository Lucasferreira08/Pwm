Este projeto demonstra o controle de um servomotor padrão utilizando PWM no microcontrolador Raspberry Pi Pico W, simulado na plataforma Wokwi. O sistema ajusta o ângulo do servo entre 0°, 90° e 180° com base no ciclo de trabalho do sinal PWM, seguido por uma rotina de movimento suave contínuo.
